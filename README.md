# 📊 Employee Attrition Analysis — Power BI


# Project Overview 
The project follows an end-to-end data analytics workflow:

**Original Dataset → Data Cleaning → SQL Analysis → Power BI → Interactive Dashboard**
The objective is to transform raw employee data into meaningful insights that can support HR decision-making.

# Dataset: Synthetic IBM HR Analytics dataset (Kaggle).


# Objectives 
* Analyze overall employee workforce
* Measure employee attrition and attrition rate
* Identify job roles and departments with higher attrition
* Analyze employee demographics
* Examine overtime and its relationship with attrition
* Analyze employee satisfaction and work-related factors
* Explore income, experience, tenure, and other employee characteristics
* Build an interactive HR analytics dashboard in Power BI

# Power BI Dashboard
The cleaned dataset and analysis were used to create an interactive **HR Analytics Dashboard** in Power BI.
The dashboard focuses on key HR metrics and employee attrition patterns.
Dashboard Analysis
The dashboard provides analysis of areas such as:
* Attrition by job role
* Employee demographics
* Department-level analysis
* Overtime
* Age groups
* Employee-related HR factors
* Attrition patterns
Interactive slicers allow users to filter the dashboard and analyze the workforce from different perspectives.

4. Which departments have higher attrition?
